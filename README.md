# New browser (name to be decided)

A desktop browser for Windows and Linux with its own look: tabs drawn as a trail of
stars, one floating command bar (the Helm), and optional AI that works with a local
model, an API key or a self-hosted Odysseus server.

**Status:** planning done, building starts at Phase 0. See `docs/STATUS.md`.

This project lives on the `Constellations` branch of `13LA7E/Odys-Brows`. The old Odyssey browser is on `main`.
